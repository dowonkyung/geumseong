# 금성도청 메인화면

새소식 게시판: `news.html`(목록·상세), `news-write.html`(웹 글쓰기), `news-preview.html`(첨부파일 바로보기). **공개 게시 활성화에는 Supabase 프로젝트 연결이 필요합니다.** 초기 SQL·관리자 등록·설정 방법은 [BOARD_SETUP.md](BOARD_SETUP.md)를 확인하세요. 연결 전에는 이 기기에 임시저장·미리보기가 가능하며 공개 게시 버튼은 비활성화됩니다.

새빛민주공화국의 가상 지방자치단체 금성도 홈페이지입니다. 제공받은 성남시청 저장본의 배너 크기(데스크톱 844 × 440px), 32px 모서리, 좌우 화살표, 우측 하단 컨트롤, 검색·바로가기 배치를 반영했습니다. 상징색은 #2A5CAA이며, 국기와 상단 로고는 사용자가 제공한 SVG 원본을 그대로 사용합니다. 메뉴와 홍보 내용은 금성도에 맞추어 작성했습니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 빌드나 설치 없이 동작하는 HTML/CSS/JavaScript입니다. GitHub Pages에도 그대로 사용할 수 있습니다.

## 구현 범위

- 요청한 GNB 전체 계층과 전체 메뉴, 모바일 메뉴
- 이미지 배너: 원본과 같은 Swiper 라이브러리, 5초 자동 전환, 500ms 가로 슬라이드, 순환 재생, 터치 스와이프, 이전·다음·정지·재생
- Pretendard GOV Regular/Bold 웹폰트 자체 호스팅(라이선스 포함)
- 새소식·고시 공고·입찰 공고·입법 예고·보도자료 탭
- 현재 메뉴 및 예시 게시물 대상 검색
- 화면 확대와 키보드 접근성, 반응형 레이아웃

새소식 목록·상세·글쓰기·첨부파일 뷰어가 구현되어 있으며, Supabase 연결 후 관리자 로그인과 공개 게시를 사용할 수 있습니다. 연결 전 예시 게시물과 이 기기 임시저장을 제공합니다. 다른 메뉴의 상세 서비스와 실제 민원 접수는 준비 중입니다.

## 배너 이미지 교체

1. `assets/banners/`에 이미지를 넣습니다. 권장 크기: 844 × 440px. JPG, PNG, WebP, SVG를 사용할 수 있습니다.
2. `banners.js`의 `src`를 해당 경로로 바꾸고, 이미지 내용을 설명하는 `alt`를 작성합니다.
3. 연결 메뉴는 `page`로, 실제 URL은 `href`로 지정합니다. 배열 항목을 추가하면 페이지 수가 자동 갱신됩니다.

현재 배너는 금성도용 예시 이미지입니다. 화면의 모션 감소 설정이 켜져 있으면 자동 재생과 전환 애니메이션이 기본 비활성화되며, 재생 버튼으로 자동 재생을 켤 수 있습니다.

## 외부 자산

- Pretendard GOV: 원본에서 사용한 파일을 포함합니다. `assets/fonts/LICENSE.txt` 참조.
- Swiper: 제공받은 성남시청 저장본과 동일한 배포 파일. 소스 헤더의 MIT 라이선스 고지를 보존했습니다.
- 바로가기 아이콘: 디자인 참조용 성남시청 원본 자산의 강조색을 금성도 상징색으로 수정했습니다.

## 상단 바와 도지사 섹션

- 상단은 원본의 `header-top`, `header-middle`(`top-menu`, `bottom-menu`, `logo`, `etc-menu`), `header-bottom`(`mobile-top`, `gnb`, `gnb-wrap type-depth3`) 구조를 사용합니다. 날씨와 AI 검색은 제외했습니다.
- 원본 CSS 규칙과 반응형 규칙은 `reference-layout.css`, 기관명·메뉴 개수 및 독립 페이지에 필요한 조정은 `header-mayor.css`에 있습니다.
- 도지사 섹션 순서: 메인 배너/생활서비스 → `mayor-section section` → 소식. 기존 `intro inner`는 제거했습니다.
- `site-content.js`의 `name`, `greeting`, `portrait`, `slogan`, `sloganAlt`, `banners`를 수정하면 도지사 이름, 인사말, 인물 이미지, 슬로건, 우측 소식 이미지를 바꿀 수 있습니다. 현재 인물은 가상의 한도윤이며 SVG 인물 이미지는 임시 삽화입니다.
- 원본 도지사 섹션의 배경 사진은 디자인 참조용 임시 자산입니다. 배경 파일은 `assets/reference/mayor_bg.png`, `mayor_bg1.png`, `mayor_bg_t.png`, `mayor_bg_m.png`에서 교체할 수 있습니다.
- 로그인·기관 사이트·다국어는 화면 안내만 제공하며 실제 인증·번역 서비스를 호출하지 않습니다.

## 소식·푸터 및 메뉴 동작

- `news-section`은 원본 `notice-content`와 같은 목록/오른쪽 알림 이미지 구성을 사용합니다. 소식 탭과 목록, 더보기, 알림 배너 컨트롤을 포함하며 CSS는 `news-footer.css`에 있습니다.
- 오른쪽 알림 이미지는 `assets/notice-01.svg` ~ `notice-03.svg`이며 권장 크기는 408 × 266px입니다. `index.html`의 `.notice-content .slide`에서 이미지 경로를 변경할 수 있습니다.
- GNB는 클릭으로 열고 같은 메뉴를 다시 클릭하거나 다른 영역을 누르면 닫힙니다. 호버로 열거나 닫지 않으며 하위 제목의 ‘바로가기’ 문구를 제거했습니다.
- 메인 배너 정지 버튼은 사용자가 제공한 SVG를 사용합니다. 재생 상태에서는 SVG 재생 아이콘으로 전환됩니다.
- 도지사 인물 이미지 하단과 슬로건 카드 상단이 맞닿습니다. 슬로건 원본은 `assets/mayor-slogan.svg`입니다.
- 푸터는 원본의 `footer-info`, `footer-logo`, `address-wrap`, `address-map`, `util` 구조와 CSS를 사용합니다. 주소·콜센터 정보는 `index.html`의 `footer`에서 수정합니다. 주소는 금성도 금성도 금성동 1, 금성콜센터는 금성 800-7070입니다. 접근성 배지는 이용 안내 링크입니다.

- 알림 더보기는 제목줄 오른쪽 원형 버튼이며, 각 슬라이더 페이지 수 표시 폭은 60px입니다. 도지사 소식 배너는 슬로건 카드 위로 40px(모바일 24px) 간격을 둡니다.

- 반응형 인물 이미지: 63.99em 이하에서는 원본의 합성 배경(mayor_bg_t.png / mayor_bg_m.png)을 사용하며, 별도 인물 이미지 가상 요소는 숨겨 중복을 방지합니다. site-content.js의 portrait는 데스크톱용입니다.

게시판 로컬 검증: 작성부서 검색, 본문 사진 삽입, 텍스트/HWP/PDF/PNG 첨부, IndexedDB 임시저장과 새로고침 복구, 첨부 다운로드, 한글 5 문서 3쪽 렌더링, PDF 렌더링·페이지 이동, PNG 표시, 모바일 가로 넘침을 확인했습니다. Supabase 프로젝트가 없어 원격 인증·RLS·업로드·공개 게시의 실서버 검증은 미실시입니다. PDF 뷰어는 PDF.js 6.4.299이며 라이브러리와 워커는 자체 호스팅합니다. PDF 종류에 따라 표준 폰트·문자맵·디코더를 고정 버전 jsDelivr에서 추가로 불러올 수 있습니다. 문서 자체를 외부 변환 서버에 전송하지 않습니다.
